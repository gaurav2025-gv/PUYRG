# PUYRG Vision

**PUYRG** means **Practice Until You Reach Goal**.

PUYRG is an AI-powered Interview Operating System for students and engineers preparing for software engineering, backend engineering, AI/ML, competitive programming, and quant/HFT careers. It is not a simple question counter or static tracker. Its purpose is to tell a user what to learn, why it matters, how much practice is enough, what is weak, and how close they are to a target role or company.

## Product Promise

PUYRG helps a user answer:

- What should I study today?
- Why is this important for my goal?
- Which topics are weak despite high solved count?
- How ready am I for Rubrik, Google, Microsoft, HFT, ICPC, or AI/ML roles?
- Which problems, projects, revisions, and mocks will improve my readiness fastest?

## Core Principle

Every feature must pass this test:

**Does this feature make the user a better engineer or a better interview candidate?**

If the answer is no, the feature should be rejected or postponed.

## Product Identity

PUYRG combines:

- Notion-style organization
- LeetCode/Codeforces progress tracking
- Roadmap.sh-style learning paths
- Company-specific interview preparation
- AI mentoring and readiness analysis
- Long-term engineering growth tracking

## Long-Term Vision

The system should eventually model 4000+ interconnected learning nodes across DSA, Core CS, Backend, System Design, AI/ML, Competitive Programming, Engineering Practices, DevOps, Projects, and Interview Skills.

The end state is a personalized report like:

```text
Rubrik Readiness: 94%
Google Readiness: 91%
Microsoft Readiness: 95%
Jane Street Readiness: 72%
ICPC Advanced Readiness: 68%

Next highest impact tasks:
- Complete 18 Tree DP problems
- Finish Go Concurrency module
- Revise OS Scheduling
- Build Redis Pub/Sub feature
- Give 3 timed mock interviews
```
