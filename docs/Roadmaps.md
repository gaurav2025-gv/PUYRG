# PUYRG Roadmaps

## Roadmap Inputs

A roadmap is generated from:

- Selected career goals
- Selected companies
- Selected roles
- Topic mastery
- Problem attempts
- Project progress
- Revision schedule
- Revision backlog
- Mastered vs solved count
- Interview deadline
- User available time

## Roadmap Output

A roadmap should contain:

- Today plan
- Weekly plan
- Monthly direction
- Revision tasks
- Problem targets
- Project tasks
- Mock interview tasks
- Readiness impact estimate

Example:

```text
To become interview ready for Rubrik:

Solve:
- 12 DP problems
- 8 Graph problems
- 3 LLD exercises
- 2 Go backend tasks

Estimated time:
- 18 days
```

## Priority Formula v1

Initial priority can consider:

```text
priority =
  company_importance
  + role_importance
  + career_goal_importance
  + weakness_score
  + revision_due_score
  + memory_decay_score
  - mastery_score
```

This formula should remain configurable.
