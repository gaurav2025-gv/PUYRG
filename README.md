# PUYRG

**Practice Until You Reach Goal**

PUYRG is an AI-powered Interview Operating System for company-specific, role-specific, and career-specific preparation.

It is designed to combine:

- Knowledge graph based learning
- Goal-based practice targets
- Company and role readiness scores
- Learning Ledger progress tracking
- Revision Engine with 3 required revisions per solved question
- AI recommendations
- Roadmaps for SWE, Backend, AI/ML, HFT, and CP goals

The project is currently in the documentation and product design phase.
